# Recipe Box

A recipe box and shopping list for iPhone that works with no internet.

Open https://crowsell64.github.io/recipe-box/ in Safari, tap Share, then Add to Home Screen.

- Recipes and the shopping list are stored on the phone, not here.
- `recipes.json` holds recipes Claude has cleaned up; the app adds new ones the next time it opens with signal.
- To release an update, change `VERSION` in `sw.js`.
